# LibreLux release checklist

- TypeScript passes with no diagnostics.
- Lint passes with no errors or warnings.
- Production build completes.
- Chromium, Firefox, WebKit, and tablet projects pass the release suite.
- No uncaught page errors or error-level console messages are observed.
- Optics presets show a selected outline, preview continuously, respond to Amount, and clear after Apply.
- Local catalog data survives reload.
- Keyboard focus, 200% text, high contrast, and reduced motion remain usable.
- Automated WCAG A/AA scan has no serious or critical findings.
- TIFF/DNG/HDR encoder tags and bit depth pass the static regression audit.
- Installable AI, measured-optics, spectral-film, and history packs resolve from their authoritative sources.
- Published release reports healthy and its live worker log is clean.
